Keeps the Wi-Fi alive; logs Wi-Fi changes.

- While monitoring runs, the app asks Android to keep the Wi-Fi connection alive. Some phones drop a Wi-Fi network that has no internet when mobile data is on, which cut the link between the phones.
- Diagnostics now records when the Wi-Fi network appears, disappears, or gains/loses internet
- A hint appears when the Wi-Fi has no internet

يحافظ على اتصال الـ Wi-Fi أثناء المراقبة. بعض الجوالات تقطع شبكة Wi-Fi ما فيها إنترنت لما تكون بيانات الجوال شغّالة، وهذا كان يقطع الاتصال بين الجوالين. وصار التشخيص يسجّل ظهور واختفاء الشبكة وحالة الإنترنت.
